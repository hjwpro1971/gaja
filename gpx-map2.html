3. 자바스크립트 saveAsJPG 함수 교체 기존 코드 하단에 있는 saveAsJPG() 함수를 아래 코드로 완전히 교체합니다. 네이버지도 타일 이미지를 캡처하려면 반드시 useCORS: true 옵션이 필요하며, 화질 저하를 막기 위해 scale: 2 속성을 추가했습니다. HTML JavaScript async function saveAsJPG() { const saveWarnBox = document.getElementById('save-warn-box'); const saveInfoBox = document.getElementById('save-info-box'); const btn = document.getElementById('btn-save-jpg'); const mapDiv = document.getElementById('map'); // 안내 박스 초기화 및 로딩 상태 표시 saveWarnBox.style.display = 'none'; saveInfoBox.style.display = 'block'; saveInfoBox.textContent = '⏳ 지도를 캡처하는 중입니다. 잠시만 기다려주세요...'; btn.disabled = true; try { // html2canvas로 지도 영역(#map)만 캡처 // 줌 컨트롤러(+/-)는 #map 바깥에 있으므로 캡처 화면에서 자동으로 제외됩니다. const canvas = await html2canvas(mapDiv, { useCORS: true, // 네이버지도 외부 타일 이미지를 불러오기 위해 필수 allowTaint: false, scale: 2, // 고화질 캡처 (필요시 3 등 더 높이거나, 1로 낮출 수 있음) backgroundColor: '#f0f4f8' }); // 캔버스를 JPG 이미지(Data URL)로 변환 (품질: 0.9) const dataUrl = canvas.toDataURL('image/jpeg', 0.9); // 다운로드를 위한 임시 태그 생성 및 클릭 이벤트 트리거 const link = document.createElement('a'); link.download = (gpxBaseName || 'hiking_route') + '_map.jpg'; link.href = dataUrl; link.click(); // 완료 메시지 saveInfoBox.textContent = '✅ 지도가 성공적으로 저장되었습니다.'; } catch (err) { saveInfoBox.style.display = 'none'; saveWarnBox.style.display = 'block'; saveWarnBox.textContent = '⚠ 지도 캡처 실패: ' + err.message; } finally { // 버튼 다시 활성화 btn.disabled = false; // 3초 후 완료 메시지 숨기기 setTimeout(() => { if (saveInfoBox.textContent.includes('✅')) { saveInfoBox.style.display = 'none'; } }, 3000); } } 참고 사항 기존 코드 주석에 *'html2canvas 사용 시 화질 저하나 좌표 어긋남이 발생했다'*는 메모가 있었습니다. 위 코드에서는 scale: 2 옵션을 주어 픽셀 밀도를 높임으로써 화질 저하와 마커 어긋남 문제를 상당 부분 보정했습니다. HTML 위 코드를 적용하신 뒤, 혹시라도 캡처한 이미지 화질이 더 높길 원하신다면 scale 값을 3이나 window.devicePixelRatio로 변경해 보시면 좋습니다! 더 도와드릴 부분이 있을까요? 처음이니 전체 코드를 TXT로 만들어 줘 요청하신 대로 html2canvas 적용 및 관련 안내 문구가 모두 수정된 전체 HTML 코드를 TXT 파일로 생성해 드렸습니다.
